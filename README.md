# [냉털한끼 - 레시피 웹 애플리케이션](https://bejewelled-cuchufli-22921c.netlify.app/)

![image](https://github.com/user-attachments/assets/da9462c1-c5b4-45e9-bef9-b2f45d540a17)

## 1. 개요

냉털한끼는 사용자들이 다양한 요리 레시피를 검색하고 저장할 수 있는 웹 애플리케이션입니다. 식품안전나라 공공 API를 활용하여 신뢰할 수 있는 레시피 정보를 제공합니다.

## 2. 목표

- 사용자들에게 신뢰할 수 있는 레시피 정보 제공
- 직관적인 UI/UX를 통한 손쉬운 레시피 검색 및 저장 기능 제공
- 반응형 디자인을 통한 모든 디바이스에서의 최적화된 사용자 경험 제공

## 3. 주요 기능

### 3.1 레시피 검색 및 필터링

- 전체 레시피 목록 제공
- 저열량/저염식 등 카테고리별 필터링
- 페이지네이션을 통한 효율적인 레시피 탐색

### 3.2 북마크 기능

- 로그인/비로그인 사용자 모두 이용 가능한 북마크 기능
- 게스트 사용자: 제한된 수의 레시피 북마크 가능
- 로그인 사용자: 무제한 레시피 북마크 가능

### 3.3 상세 레시피 정보

- 레시피 이미지 및 상세 조리 방법
- 영양 정보 제공 (열량, 탄수화물, 단백질, 지방, 나트륨)
- 조리 단계별 이미지와 설명
- URL 공유 기능

### 3.4 사용자 관리

- 회원가입/로그인 기능
- 게스트/회원 모드 구분

## 4. 기술 스택

### 4.1 프론트엔드

- React.js
- Redux Toolkit (상태 관리)
- React Query (서버 상태 관리)
- React Bootstrap (UI 컴포넌트)
- React Router (라우팅)

### 4.2 추가 라이브러리

- react-multi-carousel (캐러셀 기능)
- react-paginate (페이지네이션)
- axios (HTTP 클라이언트)

## 5. 사용자 인터페이스

### 5.1 반응형 디자인

- Desktop (1024px 이상)
- Mobile (767px 이하)

### 5.2 주요 페이지

- 홈페이지 (추천 레시피, 랜덤 레시피 표시)
- 레시피 목록 페이지
- 레시피 상세 페이지
- 북마크 페이지
- 로그인/회원가입 페이지
